# PetroVision ML Models

The ML Models module is responsible for analyzing fuel station operational data and generating AI-based performance insights and recommendations.

---

# Main Functions

* Station performance prediction
* Recommendation generation
* Trend analysis
* Performance ranking
* AI-based reporting support

---

# Model Files

## Trained Models

Contains trained machine learning models and supporting configuration files.

Files include:

* performance_model_city.json
* performance_model_station.json
* performance_model_station_time.json
* performance_model_year.json
* recommendation_rules.json
* global_drivers.json
* feature_cols_station_time_holdout.pkl
