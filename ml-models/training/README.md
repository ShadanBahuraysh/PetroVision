# Training

This folder contains the notebooks and experiments used during the machine learning training process.

## Contents

* Model training notebooks
* Evaluation experiments
* Feature engineering workflows
* Model testing experiments

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* XGBoost

## Purpose

These notebooks were used to train, evaluate, and improve the AI models used in the PetroVision system.

## Dataset

The machine learning models were trained using a dataset containing 90,000 records from 45 fuel stations with 51 features covering the years 2024–2025.

The dataset is stored separately on Google Drive and was used only during the training phase. The deployed PetroVision system uses the trained models located in the trained_models directory and does not require the dataset during runtime.
