# PetroVision Database

The PetroVision database stores all operational, loyalty, authentication, and analysis-related data used by the system.

The project uses Supabase PostgreSQL as the database platform.

---

# Main Database Modules

## User Management

Stores:

* User accounts
* Authentication data
* User roles
* OTP verification data

## Loyalty System

Stores:

* Customer points
* Membership tiers
* Loyalty transactions
* Rewards and offers

## Station Data

Stores:

* Station information
* Station locations
* Operational metrics
* Performance indicators

## Analysis Reports

Stores:

* Generated reports
* Recommendation results
* Ranking summaries
* AI analysis outputs

---

# Database Features

* Centralized cloud database
* Real-time data access
* Secure API integration
* Role-based access support
* Scalable PostgreSQL infrastructure

---

# Database Platform
