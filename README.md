# PetroVision ⛽✨

PetroVision is an AI-powered fuel station analytics and customer loyalty platform designed to support operational decision-making and improve customer engagement.

The system combines:

* AI-based station performance analysis
* Recommendation generation
* Interactive dashboard analytics
* Fuel station monitoring
* Customer loyalty and rewards
* Digital offers and memberships

## Main Features

### Admin Dashboard

* Monitor station performance
* Run AI analysis
* View KPIs and ranking
* Compare stations
* Export reports
* View operational recommendations
* Interactive station map

### Customer Application

* View nearby stations
* Earn and redeem points
* Access loyalty rewards
* View available offers
* Manage membership level
